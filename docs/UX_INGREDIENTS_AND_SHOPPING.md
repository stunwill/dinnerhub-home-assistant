# Ingredient, category, image and shopping-list UX

DinnerHub 0.1.3 introduces:

- reusable ingredient autocomplete with pill selection
- automatic creation of ingredients that do not yet exist
- multi-select meal categories with the ability to add new categories
- client-side image resizing and persistent image storage in the recipe record
- CSV shopping-list export for the visible 7-day or 14-day plan

The shopping-list export includes every ingredient used by planned recipe entries in the selected planning period, together with quantity, unit and the meals that require it.
