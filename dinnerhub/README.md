# DinnerHub Home Assistant App

DinnerHub provides a family-friendly meal planner and recipe database inside Home Assistant.

## Included in this development release

- Home Assistant Ingress interface
- Home Assistant user identity headers
- Persistent local SQLite database
- Meal and ingredient API
- Seven-day and fourteen-day planning
- Health and readiness endpoints
- Audit trail foundation

See [DOCS.md](DOCS.md) for installation and usage.
